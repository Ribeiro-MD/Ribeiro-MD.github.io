HistóricoHistory

A API pública só dá o total atual. A evolução vem de registos guardados ao longo do tempo:The public API only gives the current total. The history comes from snapshots saved over time:

  1. Todos os dias um script no GitHub Actions guarda os downloads dos meus mods em historico.js.Every day a GitHub Actions script saves my mods' downloads to historico.js.
  2. Cada vez que abres esta página, fica também um registo no teu browser (no máximo um a cada 30 min).Each time you open this page, a snapshot is also kept in your browser (at most one every 30 min).
  3. Se tiveres mods no CurseForge, podes importar o CSV de estatísticas da consola de autor (ao lado), que traz o histórico diário completo.If you have mods on CurseForge, you can import the stats CSV from the author console (next to this), which has the full daily history.

ImportarImport

Em authors.curseforge.com → Statistics → exportar CSV. Também aceita um JSON exportado daqui.On authors.curseforge.com → Statistics → export CSV. It also accepts a JSON exported from here.
